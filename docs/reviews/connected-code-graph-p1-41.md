## 1. Findings

### F1 (minor) — three silent arguments of the `config-derived` reason are unpinned
*Verified by mutation on a copy (`/tmp/claude-1000/-home-mauricio-prg-graphmind-ai-lab/5e0cf103-88e0-4462-8dd5-c8c215259772/scratchpad/an/mut/cpg`, `PYTHONPATH` pointing at it, `tests/test_packrt_unknown_args.py`).* Each mutant left all 14 tests green:
- M2 `_keyless_reason` ignores the point: `(rec["id"], p) in field_reads` → `any(q == p for _, q in field_reads)`. A `fieldAccess` read on *another call's* `a0` turns this site `config-derived`. The only negative test moves the read to another **path** (`a1`), never another **point**.
- M7 `Corpus` stores write-mode accesses too (`r["mode"] == "read"` dropped). Spec §1.4 says "a `fieldAccess` **read**"; no test plants a `mode: "write"`.
- M6 `arg_paths` stops recursing into `firstOf`. Its docstring promises "through `firstOf`"; no test has a `config-derived` slot behind a `firstOf` (no shipped pack does either: `firstOf` appears in the fastmcp/fastapi packs only, with other modes).

The mutants that matter most were killed: dropping the `modes[n] == "config-derived"` check (M1) fails `test_a_field_read_does_not_turn_a_runtime_built_slot_into_config_derived`; the resolver mutant that drops `importRef` for an unresolved import (M3) and the classifier mutants (language check, `spec`, `__tests__`, first-segment slice: M4, M5, M8, M9) also fail the intended tests.
**Fix:** three small tests in `test_packrt_unknown_args.py`: a read on a different `pointId`; a `mode: "write"` `fieldAccess`; a deep-copied pack whose `topic` slot is `{"firstOf": [{arg: a0, onUnknown: config-derived}, {arg: kw.topic}]}`. Expected values written by hand. The test file also carries its own copy of `arg_paths` (used to build the all-unknown bundle); that is fine as an independent oracle, but then M6 is exactly what it cannot catch.

### F2 (minor) — `config-derived` is unreachable from the shipped pipeline, and its facts are dropped by the assembler
*Verified by grep over `extractors/` and `ccg/`:* nothing writes a bundle record of type `fieldAccess` (the only hits are the id helper, the schema and the new reader). So with real bundles `Corpus.field_reads` is always empty, `_keyless_reason` always answers `runtime-built`, and the new branch is covered only by hand-built bundles. That is spec-conformant ("otherwise `runtime-built`"), but `qa-engineer` must not expect `possible/config-derived` for `AC6-TOP-*` from a rebuild; those rows are gate P2 and also hit `assemble/rows.py:610-626` (`provider-key-none` / `consumer-key-none`: keyless facts never become graph edges). **Action:** one line in the ledger/test plan; no code change.

### F3 (minor) — the c2 coverage probe is narrower than the RCA's, and one residual class of refs is visible
The RCA asked for language × position (call arg, decorator arg, concat/template part, attribute `mod.CONST`) × import form (`from x import N`, `import x; x.N`, alias). `test_normalize_resolver_shadow.py` covers language × {bare, concat, template} × {resolved, aliased, unresolved, unresolved-aliased, submodule} (30 cases) plus the negative (a non-imported constant of the file still resolves to the file). Not covered: the `attr` position (`mod.CONST`) and `import x; x.N`. The `attr` branch (`core.py:314-324`) never consults `constants`, so it cannot be shadowed, and a plain `import x` is not in `Resolver.alias` at all, so `x.N` stays `point-derived` unknown. Pre-existing, outside c2, not a regression. **Residual, measured (inferred, origin not traced):** after the delta, 1,953 `ref` elements in the fcs bundle still name a qname with no `constant` or `symbol` record; 104 of them name an import-bound name of the *target* file (e.g. `falkorchat/services.py::WorkflowInputRejectedError`, where `services.py` has `from .repository import … as …`: a one-hop re-export). Those do not resolve to a value either. Worth a backlog line for P1-05, not for this change.

### F4 (minor) — the units copy of the classifier takes full repo-relative `dirs`; `skipped.py` takes dirs below the unit root
`ccg/units.py:_is_skipped_test` passes `path.split("/")` of the whole repo-relative path, `skipped.py:75` passes the path below the unit root. Same pattern, different input. They diverge only for a fallback unit whose root sits *inside* a `__tests__`/`e2e` directory (`pkg/__tests__/a.js` when `pkg/sub/package.json` is a JS manifest unit, so the fallback root is `pkg/__tests__`): units now says "test" (no unit), `skipped.py` would have said "not test". Because no unit is created, `skipped.py` never sees the file, so the outcomes agree; it is also the intended direction (a test is not a unit). No action; noted so the docstring's "shared classifier" is read as shared pattern, not shared input.

## 2. Correctness of the three fixes (against RCA and spec)

**(a)** `_one` no longer raises; an unresolved `config-derived` slot on a non-`http` kind takes the existing keyless branch (`key=None`, `possible`) with reason `config-derived` iff the slot's `arg` path (through `firstOf`) has a `fieldAccess` read on `rec["id"]`, else `runtime-built` — spec §1.4 text. `modes[n]` is safe for every `n in unresolved`: a `mount` placeholder is `drop` and returns earlier. An `http` slot with `config-derived` (N-27 rejects it in packs) would fall through to the `http` branch rather than raise; harmless, pack-validated. The old `UnsupportedSubject` import is still used elsewhere. The guard (`test_every_default_pack_degrades_an_all_unknown_site_instead_of_raising`) is generated from `DEFAULT_PACKS` × rules; it fails on HEAD (run on the export: 1 guard + 5 reason tests red), with a non-vacuity test. The only behaviour difference is for a name that is both in `alias[file]` and in `constants[path]`, i.e. the import-bound name Joern lists as a module assignment. A file that imports `N` and later rebinds `N` at module level (rare; `try: from x import N / except ImportError: N = 1`) now resolves to the import. Accept; state it in the docstring if wanted.
**(b1)** a JS file the classifier calls a test no longer makes a fallback unit; a manifest unit is untouched (`test_a_manifest_unit_with_no_source_at_all_is_still_a_unit`), a mixed fallback directory keeps its unit through the non-test sibling, Python is untouched. Mutants M4/M5/M8/M9 (language check, `spec`, `__tests__`, first-segment slice) each add failures beyond the copy's six env-only baseline failures.

**Interaction.** (a) needs (c2) to pass `TOPIC_ORDERS`/`PREFIX` through as constants rather than unknown; (c2) feeds `kafka`/`fastapi` constants only through `ref`s that the Corpus resolves against `constant` records, so no coupling beyond the RCA's.
