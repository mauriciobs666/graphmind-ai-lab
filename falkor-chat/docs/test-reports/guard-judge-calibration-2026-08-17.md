## Materiality-probe check (ca-04/05/08 vs. cs-04)

**Bloc criterion: Passed.** Archived §7's blocker rule is conjunctive — "the materiality probes
fail as a bloc (ca-04/05/08 suspended AND cs-04 advanced)" — and it did not trigger: `ca-05`
correctly advanced and `cs-04` correctly suspended, so the bloc precondition is false regardless
of the other two probes. This is a correct, mechanical, non-retroactive application of the rule as
written.

**But 2 of the 3 individual probes missed, and it is worth naming plainly rather than folding into
a bare "Passed."** `ca-04` and `ca-08` are themselves the report's own two G2 misses (the `fn=2` in
the understanding-path confusion matrix above), and they are exactly the fixture's designed
materiality probes — cases where `missing` is non-empty but the missing item is immaterial to
*research* (a presentation preference for `ca-04`, the user's own environment detail for `ca-08`),
so the correct label is `advance`. The judge suspended both, and its rationale in each case echoes
the `missing` field's content almost verbatim rather than reasoning about research-sufficiency:
`ca-04` — *"The user has not specified a preferred summary length, which is necessary to research
and tailor the summary appropriately"* — treats a presentation preference as research-blocking;
`ca-08` — *"The user has not provided their current session store configuration, which is
necessary to assess the relevance and applicability of the trade-offs..."* — treats the user's own
config, needed only to tailor the answer, the same way. This is a real, non-gating,
individually-diagnostic pattern — exactly what archived §8 item 8 calls "worth more than any
aggregate at this sample size" — even though n=2 is far too small to call it systematic with
confidence, and it does not reopen the gate: the bloc criterion is unambiguously false, G2 already
counts both misses in its 9/11, and the "wire" verdict stands unchanged.
